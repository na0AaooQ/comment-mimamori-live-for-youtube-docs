Our approach

The extension is designed to respect your privacy by handling comment text and matching results within your browser.
This is a provisional privacy explanation for prototype v0.1.0, based on its current implementation.

We distinguish between comment processing by the extension, saved settings, backup files you save, and hosting of this website.

Comment text and matching results

The current extension processes supported comments and matching results in browser memory.

  • It does not send comment text to an external server for checking.
  • It does not persistently store comment text.
  • It does not transmit or persistently store matching results.
  • It does not use external AI to check comments.

This describes processing by this extension.
YouTube’s own storage and transmission of comments are handled under YouTube’s service policies.

Settings stored locally

The following settings are saved in chrome.storage.local, Chrome’s local extension storage:

  • Your saved “Words I’d Rather Avoid”
  • The Master ON/OFF setting for all saved words
  • Individual ON/OFF settings for each word
  • The display language preference: Automatic, Japanese, or English

Saved words are stored as settings.
Comment text and matching results are not saved as settings.
Settings use Chrome’s local storage area, not its cloud sync storage area.

You can delete saved words individually in Options or use Reset.
Reset does not change your display language preference.

Export, Import, and JSON files

You can export saved words, including words set to OFF, and their Master and individual ON/OFF settings to a local JSON file.
Unsaved input, your display language preference, and the 13 standard terms are excluded.

Exported files contain your saved words in plain text.
Check where you save them and whom you share them with.
The extension has no feature that uploads these files to an external server.

After you review a selected JSON file, Import replaces all current saved-word settings.
It does not append to your existing words or change your display language preference.

See Export and Import for instructions, and follow the D-1 procedure to apply setting changes.

What the current extension does not do

  • Judge a commenter’s character or penalize commenters
  • Automatically delete comments
  • Use external AI to check comments
  • Collect usage information through external analytics or telemetry

The pause lets you choose whether to view a comment.
These statements describe the current implementation; the explanation will be reviewed if features change.

This website and GitHub Pages

GitHub Pages is the hosting destination for this website.
Hosting-related processing when you visit a web page is separate from comment matching by the extension.

When you visit a page on GitHub Pages, GitHub logs and stores your IP address for security purposes, whether or not you are signed in.
See GitHub’s documentation on data collection and the GitHub Privacy Statement.

These web pages do not include external analytics, telemetry, external CDNs, or external JavaScript.
If you follow a link to an external website, that website’s data practices apply.

Future updates

This is a prototype in development.
This explanation may be updated as features change.

Before a formal release or Chrome Web Store submission, we plan to review the implementation, stored information, external communications, and user documentation again.
This provisional page does not guarantee the legal completeness of a final privacy policy.
