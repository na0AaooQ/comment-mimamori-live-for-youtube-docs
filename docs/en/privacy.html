Our approach

This Privacy Policy describes how information is handled by the current implementation of こめんとみまもり Live v0.2.0 BETA and its public documentation website.

こめんとみまもり Live is designed to respect your privacy by handling comment text and matching results within your browser.

This policy covers comment processing by the extension, saved settings, backup files you save, and website hosting and embedded videos.

YouTube comment text and matching results

This Google Chrome extension processes supported YouTube comment text and matching results within your browser.

  • The extension does not send comment text to an external server for checking or send matching results outside your browser.
  • It does not persistently store comment text or matching results.
  • It does not use external AI to check comments.

This describes how the extension processes comments. YouTube’s own storage and transmission of comments are handled under YouTube’s service policies.

Settings stored on your device

The extension stores these settings on your device in Google Chrome’s local storage area (chrome.storage.local).

  • Words you’ve added under “Words I'd Rather Avoid”
  • The ON/OFF setting for “Pause for Saved Words”
  • Individual ON/OFF settings for each word
  • The display language preference (Automatic, Japanese, or English)

Your saved words are stored as settings. YouTube comment text and matching results are not stored as settings.
The extension does not use Chrome cloud sync for these settings.
It temporarily keeps information in your browser, such as which open screens to update after a settings change.

You can delete saved words individually on the Settings page. Reset deletes all saved words and their individual settings, turns “Pause for Saved Words” ON, and leaves you with zero saved words.
Reset keeps your display language preference. Standard Pause continues to check for the 13 standard words and phrases independently of your saved words’ ON/OFF settings.

Export, Import, and backup files

You can export saved words, including words set to OFF, and their overall and individual ON/OFF settings to a backup file (JSON format) on your device.
The file excludes unsaved input, your display language preference, and the 13 standard words and phrases.

Exported files contain your saved words in plain text.
Check where you save them and whom you share them with.
The extension has no feature that uploads these files to an external server.

After you review the selected file, Import replaces all your current saved words and their ON/OFF settings.
Your display language stays the same.

See Export and Import for instructions, and see how to check for changes in the comments after saving.

What the current extension does not do

  • Judge a commenter’s character or penalize commenters
  • Automatically delete comments
  • Use external AI to check comments
  • Collect usage information through external analytics or telemetry

The pause lets you choose whether to view a comment.
These statements describe the current implementation; the explanation will be reviewed if features change.

This website and GitHub Pages

GitHub Pages is the hosting destination for this website.
Hosting-related processing when you visit a web page is separate from comment matching by the extension.

When you visit a page on GitHub Pages, GitHub logs and stores your IP address for security purposes, whether or not you are signed in.
See GitHub’s documentation on data collection and the GitHub Privacy Statement.

This website does not use its own external analytics or telemetry. The website's own CSS, JavaScript, and instructional images are served from the same website.
If you follow a link to an external website, that website’s data practices apply.

Embedded YouTube Videos

The User Guide on this website includes demonstration videos using YouTube's Privacy Enhanced Mode.

When you choose to display a video, your browser connects to YouTube and related services. For information about how data is handled when displaying or watching videos, please review Google's Privacy Policy.

You can use the User Guide without displaying or watching the videos.

Future updates
