Before you begin

This sample guide covers v0.1.0 of the Google Chrome extension, a prototype still in development.
It is not published in the Chrome Web Store.
It is intended for people who have already loaded the Google Chrome extension for development testing.

The Google Chrome extension covers regular messages in YouTube live stream comments (Live Chat).
On regular videos, YouTube Shorts, and individual video comments pages in YouTube Studio, it covers comments that are not replies on supported layouts.
The extension uses the same rules in all four places to check for the 13 standard words and phrases and any saved words you’ve turned on.
The extension’s interface supports Japanese and English.
Replies, Super Chat, and similar messages are outside the scope, and unfamiliar page layouts are unverified.
See the current scope.

Open settings for こめんとみまもり Live

  1. In Chrome’s toolbar, open the Extensions menu and select こめんとみまもり Live (listed as “こめんとみまもり Live Protect-first PoC” in the development build). This opens a small settings window called a pop-up.
    If you’ve pinned the extension to the toolbar, you can also select its icon there.
  2. Select “Open Settings” to open the Settings page in a new tab.

The pop-up shows the product name and version.
Use the Settings page to change saved words and the display language.

Settings and display language

On the Settings page, you can change the display language, manage saved words, learn about Standard Pause, back up settings, and reset them.
Changes to your saved words are saved automatically after each action. Check the save result on the page.

Choices under “Display Language / 表示言語”

  • Automatic (Chrome's display language) uses Japanese if Chrome displays in Japanese, and English otherwise.
  • 日本語 / English uses the selected language for Settings, the pop-up, and the extension’s interface in Live Chat, regular video comments, Shorts, and individual video comments in Studio.

Your language preference is saved automatically.
If you are entering or editing a word, a confirmation appears before switching.
Unsaved input is cleared after the language change is successfully saved, so save any edits you need first.

The pop-up uses the saved language the next time it opens.
After saving, the extension tries to update the display language in open, supported comment sections.
Updates may take time or fail to appear on some screens.
If the language does not change, close and reopen the affected Live Chat or Shorts comments panel, or reload the affected page.

Changing only the display language preserves comment decisions, which comments are hidden, and which comments you’ve revealed manually.
The preference changes the Google Chrome extension’s interface language and leaves comment text and saved words as written.
This website has its own language switch, independent of the Google Chrome extension’s preference.

Manage Words I'd Rather Avoid

After each action, check the save result on the Settings page and follow the steps to check for changes in the comments.

  1. Add: enter a word or phrase of 2–50 characters under “Add a Word or Phrase,” then select “Add.”
    You can save up to 30 entries.
  2. Edit: select “Edit” beside a saved word, make your changes, then select “Save.”
    Select “Cancel” to discard the edit.
  3. Delete: select “Delete” for the entry and confirm.
  4. ON/OFF for all saved words: use “Pause for Saved Words” to turn the pause for all saved words ON or OFF.
  5. Individual ON/OFF: use the switch for each word to include or exclude it from matching.

Duplicate entries, line breaks, and some special characters are not accepted.
Follow the input guidance if a message appears.

Standard Pause is always active.
The extension still checks for the 13 standard words and phrases when you turn the pause OFF for all saved words or for individual words.

Use the pause in YouTube Live Chat during live streams

The extension checks supported comments while their text is hidden.
Comments that do not need a pause appear automatically. Comments that need a pause stay hidden behind a notice.
If you want to read it, select “View Comment” for that comment.
In Japanese, the button is labeled “内容を見る”.

“View Comment” shows only the comment you choose.
The comment may be hidden again if its text or other details change.

The extension does not automatically delete comments, judge commenters, or penalize anyone.
A comment may remain hidden if it cannot be checked.
Protection is not guaranteed for every comment or display path.

When you save changes to your word settings or display language, the extension tries to update open Live Chats.
If the change does not appear, close and reopen the affected chat.

Use the pause in regular video comments

Open the comments section on a regular YouTube video page (/watch or /live).
The extension keeps supported comments that are not replies hidden while checking for the 13 standard words and phrases and any saved words you’ve turned on.
Comments that do not need a pause appear automatically. Comments that need a pause stay hidden behind a notice.
Select “View Comment” to reveal only that comment.

When you switch videos without reloading on a supported page, the extension clears any reveals made with “View Comment” on the previous video and tries to resume checking comments on the new video.
If the extension does not resume checking comments, or you see a reload prompt, reload the page.
Replies are outside the scope. Some layouts have yet to be verified.

For Shorts, see Use the pause in YouTube Shorts comments.

Use the pause in YouTube Shorts comments

The extension covers comments that are not replies on supported Shorts layouts.

  1. Open a YouTube Shorts video and select the comments button to open the comments panel.
  2. Comments that need a pause stay hidden, with a “View Comment” button. Comments that do not need a pause appear automatically.
  3. To read a hidden comment, select “View Comment” for that comment. Only the selected comment is revealed.
  4. If you close and reopen the comments panel, the extension checks the comments again using your current settings. Comments you previously revealed are hidden again if they still need a pause.

If changes to your settings do not appear, or you see a message asking you to reload, reload the YouTube Shorts page.

Replies are not currently covered by the pause feature.

Video comments in Studio

In YouTube Studio, select a video and open its Comments page.
The extension keeps supported comments that are not replies hidden while checking for the 13 standard words and phrases and any saved words you’ve turned on.
Comments that do not need a pause appear automatically. Comments that need a pause stay hidden behind a notice.
Select “View Comment” to reveal only that comment.

When you switch to another video within Studio, the extension may keep supported comments hidden and ask you to reload.
If prompted, reload the page and check the current video’s comments.
Replies and the channel-wide and Shorts-specific comment management pages are outside the scope.

Apply settings for your saved words to comments

When you save additions, edits, deletions, ON/OFF changes for all saved words or individual words, an import, or a reset, the extension tries to update supported comment sections already open in YouTube Live Chat, regular videos, Shorts, and Studio.

  1. Change the settings for your saved words on the Settings page.
  2. Check the Settings page for the save confirmation.
    If the save result is unclear, see Limitations and troubleshooting.
  3. Check whether the change appears in the affected comments.
    If it does not, close and reopen the affected Live Chat or Shorts comments panel, or reload the affected page.
    You can also close and reopen the page.

The save confirmation on the Settings page means your settings were stored.
Updates may take time or fail to appear on some screens.

Export your settings to a backup file

  1. Clear the input field, and save or cancel any word you are editing.
    Export is unavailable while entering or editing a word.
  2. Select “Export” under “Backup” and save the backup file (JSON format) on your device.

The file contains your saved words, including words set to OFF, and the ON/OFF settings for all saved words and for each word.
It does not include unsaved input, your display language preference, or the 13 standard words and phrases.

The backup file contains your saved words exactly as stored, in plain text.
Take care when choosing where to save it and whom to share it with.

Import your settings from a backup file

  1. Export your current settings first if you want to keep a copy.
  2. Clear the input field and save or cancel any active edit.
    Select “Import” under “Backup,” then choose a backup file exported by this extension.
  3. Review the entry counts and ON/OFF information shown.
    If correct, select “Import and Replace”.
    Select “Cancel” to stop.
  4. Check the save confirmation, then follow the steps to check for changes in the comments.

Import replaces the whole set.
Your saved words and their overall and individual ON/OFF settings are replaced with the contents of the file you chose.
It does not change the display language or standard rules.

Reset your settings for saved words

  1. Clear the input field and save or cancel any active edit.
    Export a backup first if needed.
  2. Select “Reset” under “Reset Settings” and read the confirmation.
  3. Select “Confirm Reset” to continue, or “Cancel” to stop.
  4. Check the save confirmation, then follow the steps to check for changes in the comments.

Reset deletes all saved words and their individual ON/OFF settings. The defaults are “Pause for Saved Words” ON and 0 saved words.
It does not change the display language preference or the matching rules for the 13 standard words and phrases.

Limitations and troubleshooting

  • If changes to your word settings or display language do not appear after saving, close and reopen the affected Live Chat or Shorts comments panel, or reload the affected page.
    If the pop-up’s language does not change, reopen it.
  • If comments stay hidden and you see a reload prompt, follow it to reload the page.
    If the extension does not resume checking comments after you switch regular videos, or Studio prompts you to reload after switching videos, reload the page and check the current video’s comments.
  • If the Settings page says it could not confirm whether changes to your saved words were saved, close all open YouTube Live Chats and supported comment screens for regular videos, Shorts, and Studio.
    Then reload the Settings page and check what was saved.
  • If you are unsure whether your display language was saved, reload the Settings page to check the preference.
  • After updating the development build, reload the extension in Chrome’s Manage Extensions page, then reload or reopen the affected YouTube pages.
  • Check the current scope.
    Replies, Super Chat, and other message types are outside the scope or unverified.
  • Changes to YouTube’s pages may affect the extension.
    Some areas are not yet implemented or verified.

The absence of a pause does not mean a comment is safe.
If you are unsure about the Google Chrome extension’s behavior, you can choose to step away from the comments.
