Before you begin

This sample guide covers v0.1.0 of the Google Chrome extension, a prototype still in development.
It is not published in the Chrome Web Store.
It is intended for people who have already loaded the Google Chrome extension for development testing.

The Google Chrome extension covers regular messages in YouTube live stream comments (Live Chat).
It also covers supported top-level comments on regular video pages and on comments pages for individual videos in YouTube Studio.
All three use the same rules to check for the 13 standard terms and your enabled saved words.
The extension’s interface supports Japanese and English.
Replies, Super Chat, and similar messages are outside the scope, and unfamiliar page layouts are unverified.
See the current scope.

Open the popup for こめんとみまもり Live settings

  1. Select こめんとみまもり Live in Chrome’s Extensions menu to open the options popup.
    If you’ve pinned the extension to the toolbar, you can also select its icon there.
  2. Select “Open Settings” to open the options page in a new tab.

The options popup shows the product name and version.
Use the options page to change saved words and the display language.

Options and display language

The options page contains the display language preference, saved-word management, an explanation of Standard Pause, backups, and reset controls.
Saved-word actions are saved automatically; check the result shown on the page.

Automatic / 日本語 / English

  • Automatic: uses Japanese if Chrome’s UI language is Japanese, and English otherwise.
  • 日本語 / English: uses the selected language for the options page, the options popup, and the Google Chrome extension’s interface in Live Chat, regular video comments, and Studio’s video comments pages.

Your language preference is saved automatically.
If you are entering or editing a word, a confirmation appears before switching.
Unsaved input is cleared after the language change is successfully saved, so save any edits you need first.

The options popup uses the saved language the next time it opens.
After saving, the extension tries to update the display language in open, supported comment sections.
There is no guarantee that every screen will be notified, that updates will complete, or how long they will take.
If the language does not change, close and reopen the affected Live Chat, or reload the affected regular video or Studio page.

Changing only the display language preserves comment decisions, which comments are hidden, and which comments you’ve revealed manually.
The preference changes the Google Chrome extension’s interface language and leaves comment text and saved words as written.
This website has its own language switch, independent of the Google Chrome extension’s preference.

Manage Words I’d Rather Avoid

After each action, check the save result on the options page and follow the steps for applying saved-word settings to verify the change on the affected screen.

  1. Add: enter a word or phrase of 2–50 characters under “Add a Word or Phrase,” then select “Add.”
    You can save up to 30 entries.
  2. Edit: select “Edit” beside a saved word, make your changes, then select “Save.”
    Select “Cancel” to discard the edit.
  3. Delete: select “Delete” for the entry and confirm.
  4. Master ON/OFF: use “Pause for Saved Words” to turn matching for all saved words ON or OFF.
  5. Individual ON/OFF: use the switch for each word to include or exclude it from matching.

Duplicate entries, line breaks, and some special characters are not accepted.
Follow the input guidance if a message appears.

Standard rules operate independently.
The 13 standard terms remain active even if Master or an individual word is OFF.
Master is not an ON/OFF switch for the entire Google Chrome extension.

Use the pause in Live Chat

The extension hides supported comments before checking them.
Comments marked SAFE appear automatically.
For comments marked CUSHION, the text stays hidden behind a pause.
If you want to read it, select “View Comment” for that comment.
In Japanese, the button is labeled “内容を見る”.

This action, called Manual Reveal, displays only that individual comment.
It does not reveal all comments.
Permission to display it may be cleared if its text or other relevant state changes.

The extension does not automatically delete comments, judge commenters, or penalize anyone.
A comment may remain hidden if it cannot be checked.
Protection is not guaranteed for every comment or display path.

When you save changes to your word settings or display language, the extension tries to update open Live Chats.
If the change does not appear, close and reopen the affected chat.

Use the pause in regular video comments

Open the comments section on a regular YouTube video page (/watch or /live).
The extension hides supported top-level comments first and checks them for the 13 standard terms and your enabled saved words.
Comments marked SAFE appear automatically.
Comments marked CUSHION stay hidden behind a pause.
Select “View Comment” to reveal only that comment.

When you switch videos using supported in-page navigation, the extension clears manual reveals from the previous video and tries to check the current video’s comments and resume automatically.
If the comments section does not recover or you see a reload prompt, reload the page.
Replies and Shorts are outside the scope, and protection in unfamiliar layouts is unverified.

Video comments in Studio

In YouTube Studio, select a video and open its Comments page.
The extension hides supported top-level comments first and checks them for the 13 standard terms and your enabled saved words.
Comments marked SAFE appear automatically.
Comments marked CUSHION stay hidden behind a pause.
Select “View Comment” to reveal only that comment.

When you switch to another video within Studio, the extension may keep supported comments hidden and ask you to reload.
If prompted, reload the page and check the current video’s comments.
The channel-wide comment management page and replies are outside the scope.

Apply saved-word settings

After you add, edit, or delete a word, change the Master or individual ON/OFF settings, import, or reset, the extension tries to apply the saved settings to open Live Chats and supported regular video and Studio comment sections.

  1. Change saved-word settings on the options page.
  2. Confirm that saving is complete.
    If the save result is unclear, see Limitations and troubleshooting.
  3. Check whether the change appears on the affected screen.
    If it does not, close and reopen the affected Live Chat, or reload the affected regular video or Studio page.
    You can also close and reopen the page.

The save confirmation on the options page means your settings were stored.
There is no guarantee that every screen will be notified, that every screen will finish updating, or when or how quickly updates will complete.

Export: save a backup

  1. Clear the input field, and save or cancel any word you are editing.
    Export is unavailable while entering or editing a word.
  2. Select “Export” under “Backup” and save the JSON file locally.

The file contains your saved words, including words set to OFF, and the Master and individual ON/OFF settings.
It does not include unsaved input, your display language preference, or the 13 standard terms.

The JSON file contains your saved words in plain text, exactly as stored.
Take care when choosing where to save it and whom to share it with.

Import: restore a backup

  1. Export your current settings first if you want to keep a copy.
  2. Clear the input field and save or cancel any active edit.
    Select “Import” under “Backup,” then choose a JSON file exported by this Google Chrome extension.
  3. Review the entry counts and ON/OFF information shown.
    If correct, select “Import and Replace”.
    Select “Cancel” to stop.
  4. Confirm that saving is complete, then follow the steps for applying saved-word settings to check that the change appears.

Import replaces the whole set.
It replaces your saved words and Master and individual ON/OFF settings with the file’s contents; it does not add to your existing entries.
It does not change the display language or standard rules.

Reset: clear saved-word settings

  1. Clear the input field and save or cancel any active edit.
    Export a backup first if needed.
  2. Select “Reset” under “Reset Settings” and read the confirmation.
  3. Select “Confirm Reset” to continue, or “Cancel” to stop.
  4. Confirm that saving is complete, then follow the steps for applying saved-word settings to check that the change appears.

Reset deletes all saved words and their individual ON/OFF settings, returning to Master ON with 0 saved words.
It does not change the display language preference or the 13 standard matching rules.

Limitations and troubleshooting

  • If saved-word settings or the display language do not update after saving, close and reopen the affected Live Chat, or reload the affected regular video or Studio page.
    If the options popup’s language does not change, reopen it.
  • If comments stay hidden and you see a reload prompt, follow it to reload the page.
    If comments fail to recover after switching regular videos, or Studio prompts you to reload after switching videos, reload and check the current video’s comments.
  • If the options page says it could not confirm whether your saved-word settings were saved, follow its instructions.
    Close all open, supported comment screens, then reload the options page and check the saved settings.
    If you are unsure whether your display language was saved, reload the options page to check the preference.
  • Check the current scope.
    Replies, Super Chat, and other message types are outside the scope or unverified.
  • Changes to YouTube’s pages may affect the extension.
    Some areas are not yet implemented or verified.

The absence of a pause does not mean a comment is safe.
If you are unsure about the Google Chrome extension’s behavior, you can choose to step away from the comments.
