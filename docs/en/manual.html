Before you begin

This sample guide covers prototype v0.1.0, which is still in development and is not published in the Chrome Web Store.
It is intended for people who have already loaded the extension for development testing.

The main focus is regular Live Chat messages.
Video comments and Studio’s video comments page are technical proofs of concept; they do not have the same matching or bilingual interface as Live Chat.
See the current scope.

Open the Popup

  1. Select こめんとみまもり Live in Chrome’s Extensions menu, or select its icon if you have pinned it to the toolbar.
  2. Select “Open Settings” to open the Options page in a new tab.

The Popup shows the product name and version.
Use Options to change saved words and the display language.

Options and display language

Options contains the display language preference, saved-word management, an explanation of Standard Pause, backups, and reset controls.
Saved-word actions are saved automatically; check the result shown on the page.

Automatic / 日本語 / English

  • Automatic: uses Japanese if Chrome’s UI language is Japanese, and English otherwise.
  • 日本語 / English: uses the selected language for Options, the Popup, and the Live Chat pause interface.

Your language preference is saved automatically.
If you are entering or editing a word, a confirmation appears before switching.
Unsaved input is cleared after the language change is successfully saved, so save any edits you need first.

The Popup uses the new language the next time it opens.
Live Chat uses it when newly opened or reloaded.
A language-only change does not require closing all Live Chats.
Chats that are already open do not receive language changes in real time.

Switching this website’s language does not change the extension’s language preference.
Language switching for video comments and Studio’s video comment interface is not yet supported.

Manage Words I’d Rather Avoid

Before making changes, close all Live Chats using the saved-word settings procedure (D-1).

  1. Add: enter a word or phrase of 2–50 characters under “Add a Word or Phrase,” then select “Add.”
    You can save up to 30 entries.
  2. Edit: select “Edit” beside a saved word, make your changes, then select “Save.”
    Select “Cancel” to discard the edit.
  3. Delete: select “Delete” for the entry and confirm.
  4. Master ON/OFF: use “Pause for Saved Words” to turn matching for all saved words ON or OFF.
  5. Individual ON/OFF: use the switch for each word to include or exclude it from matching.

Duplicate entries, line breaks, and some special characters are not accepted.
Follow the input guidance if a message appears.

Standard rules operate independently.
The 13 standard terms remain active even if Master or an individual word is OFF.
Master is not an ON/OFF switch for the entire extension.

Use the pause in Live Chat

A pause is placed over a matching comment before you read its text.
If you want to read it, select “View Comment” for that comment.
In Japanese, the button is labeled “内容を見る”.

This action, called Manual Reveal, displays only that individual comment.
It does not reveal all comments.
Permission to display it may be cleared if its text or other relevant state changes.

The extension does not automatically delete comments, judge commenters, or penalize anyone.
A comment may remain hidden if it cannot be checked.
Protection is not guaranteed for every comment or display path.

Apply saved-word settings (D-1)

Use this sequence when adding, editing, or deleting words, changing Master or individual ON/OFF settings, importing, or resetting.

  1. Close all Live Chats.
    Include chats embedded in viewing pages, chats in Studio, and pop-out windows.
  2. Change saved-word settings in Options.
    Import or Reset also belongs at this step.
  3. Confirm that saving is complete.
    If the result cannot be confirmed, reload Options to check the saved state.
  4. Open Live Chat again.
    Newly opened chats use the saved settings.

Live updates of saved-word settings to chats that are already open have not been implemented.
Close all chats before changing the settings, then reopen them after saving.

For a language-only change, you do not need to close every chat.
Newly opened or reloaded chats use the new display language.

Export: save a backup

  1. Clear the input field, and save or cancel any word you are editing.
    Export is unavailable while entering or editing a word.
  2. Select “Export” under “Backup” and save the JSON file locally.

The file contains your saved words, including words set to OFF, and the Master and individual ON/OFF settings.
It does not include unsaved input, your display language preference, or the 13 standard terms.

The JSON file contains your saved words in plain text, exactly as stored.
Take care when choosing where to save it and whom to share it with.

Import: restore a backup

  1. Close all Live Chats using the D-1 procedure.
    Export your current settings first if you want to keep a copy.
  2. Clear the input field and save or cancel any active edit.
    Select “Import” under “Backup,” then choose a JSON file exported by this extension.
  3. Review the entry counts and ON/OFF information shown.
    If correct, select “Import and Replace”.
    Select “Cancel” to stop.
  4. Confirm that saving is complete, then open Live Chat again.

Import replaces the whole set.
It replaces your saved words and Master and individual ON/OFF settings with the file’s contents; it does not add to your existing entries.
It does not change the display language or standard rules.

Reset: clear saved-word settings

  1. Export a backup first if needed, then close all Live Chats using the D-1 procedure.
  2. Select “Reset” under “Reset Settings” and read the confirmation.
  3. Select “Confirm Reset” to continue, or “Cancel” to stop.
  4. Confirm that the reset is complete, then open Live Chat again.

Reset deletes all saved words and their individual ON/OFF settings, returning to Master ON with 0 saved words.
It does not change the display language preference or the 13 standard matching rules.

Limitations and troubleshooting

  • After changing saved-word settings, check that you closed all Live Chats before the change and confirmed saving.
    Then open a new chat.
  • Reload Options to check your saved words, Master switch, and individual ON/OFF settings.
  • Check the current scope.
    Replies, Super Chat, and other message types are outside the scope or unverified.
  • Changes to YouTube’s pages may affect the extension.
    Some areas are not yet implemented or verified.

The absence of a pause does not mean a comment is safe.
If you are unsure about the extension’s behavior, you can choose to step away from the comments.
