はじめに

このマニュアルでは、Google Chrome 拡張機能「こめんとみまもり Live」v0.2.0 BETAの操作方法をご案内します。
すでに拡張機能を読み込んでいる方を対象としています。

YouTubeライブ配信のコメント（Live Chat）のうち、通常のメッセージが対象です。
通常動画、YouTube Shorts（YouTube ショート動画）、YouTube Studioの動画別コメント欄では、拡張機能が対応する画面構成で表示される、返信ではないコメントが対象です。
いずれの画面でも、標準の13個の言葉と、登録した言葉のうちワンクッションが有効なものを、同じルールで確認します。拡張機能の表示は日本語・英語に対応しています。
返信やSuper Chatなどは対象外です。対応を確認していない画面構成もあります。
詳しくは現在の対象範囲をご覧ください。

掲載画像をクリックすると拡大できます。赤枠は、主な操作箇所や確認箇所を示しています。

キーボードでも操作できます。画像を選択してEnterキーまたはSpaceキーを押すと拡大し、Escキーで閉じることができます。

「こめんとみまもり Live」の設定画面を開く

ツールバーにアイコンを固定する方法

「こめんとみまもり Live」のアイコンをChromeのツールバーに固定すると、ポップアップを開きやすくなります。

アイコンの固定（ピン留め）は任意です。固定しなくても、「拡張機能」メニューからポップアップを開くことができます。

  1. Chromeのツールバーにある「拡張機能」メニューを開きます。
  2. 「こめんとみまもり Live BETA」のピン留めアイコンをクリックします。
  3. ツールバーに「こめんとみまもり Live」のアイコンが表示されたことを確認します。
  1. Chromeのツールバーにある「拡張機能」メニューから「こめんとみまもり Live BETA」を選びます。小さな設定画面（ポップアップ）が開きます。
    ツールバーに固定している場合は、そのアイコンからも開けます。
  2. 「詳細設定を開く」を選ぶと、設定画面（オプション）が新しいタブで開きます。

ポップアップでは製品名とバージョンを確認できます。
登録した言葉や表示言語は設定画面で変更します。

設定画面と表示言語

設定画面では、表示言語の変更、登録した言葉の管理、標準のワンクッションの確認、バックアップ、設定のリセットができます。
登録した言葉の変更は操作ごとに自動で保存されます。画面に表示される保存結果を確認してください。

「表示言語 / Language」の選択肢

  • 自動（Chromeの表示言語）：Chromeの表示言語が日本語なら日本語、それ以外なら英語で表示します。
  • 日本語／English：設定画面、ポップアップ、YouTubeライブチャット、通常動画、Shorts、Studioの動画別コメント欄で、拡張機能の表示に選んだ言語を使います。

言語設定は自動保存されます。
入力・編集中の切替には確認があり、保存成功後に未保存の入力内容がクリアされます。
必要な編集は先に保存してください。

ポップアップは次に開いたときに保存済みの言語を使います。
保存後、開いている対象のコメント欄にも新しい表示言語の反映を試みます。
すべての画面に反映される保証はなく、反映までにかかる時間も確約できません。
反映されない場合は、該当するLive ChatやShortsのコメント欄を閉じて開き直すか、該当ページを再読み込みしてください。

表示言語だけを変えても、コメントの判定結果や、コメントを隠した状態、「内容を見る」で表示した状態は変わりません。
コメント本文や登録した言葉は、元の言語のまま表示されます。
このWebページの日英切替は、Google Chrome 拡張機能の表示言語設定を変更しません。

距離を置きたい言葉を管理する

各操作の後は設定画面に表示される保存結果を確認し、コメント欄で設定の反映を確認する手順に沿って変更が反映されたか確認してください。

  1. 追加：「言葉を追加」に2〜50文字の言葉を入力し、「追加する」を選びます。
    最大30件まで登録できます。
  2. 編集：登録した言葉の「編集」を選び、内容を変更して「保存」します。
    取りやめるときは「キャンセル」を選びます。
  3. 削除：対象の「削除」を選び、確認後に削除します。
  4. 全体のON/OFF：「登録した言葉へのワンクッション」で、登録した言葉すべてに対するワンクッションを切り替えます。
  5. 言葉ごとのON/OFF：各スイッチで、その言葉をワンクッションの判定に使うかを切り替えます。

重複した言葉や改行、一部の特殊な文字などは登録できません。
入力案内が出た場合は内容を確認してください。

標準のワンクッションは常に有効です。
登録した言葉へのワンクッションを全体または言葉ごとにOFFにしても、標準の13個の言葉による判定は続きます。

YouTube Live Chat（YouTube ライブ配信）のワンクッション

対象コメントの本文は隠した状態で確認します。
ワンクッションが不要なコメントは自動で表示し、必要なコメントは内容を隠したまま案内を表示します。
読みたい場合は、そのコメントの「内容を見る」を選んでください。
英語表示のボタンは「View Comment」です。

「内容を見る」で表示するのは、選んだコメントだけです。
コメントの内容などが変わると、再び隠れる場合があります。

コメントを自動削除したり、投稿者を評価・制裁したりする機能ではありません。
判定できない場合などは本文が隠れたままになることもあります。
すべてのコメントや表示経路への保護は保証していません。

登録した言葉の設定や表示言語を保存すると、開いているLive Chatにも反映を試みます。
反映されない場合は、該当のLive Chatを閉じて開き直してください。

通常動画コメントのワンクッション

通常のYouTube動画ページ（/watch・/live）でコメント欄を開きます。
本文を隠した状態で、返信ではない対象コメントを、標準の13個の言葉と登録した言葉のうちワンクッションが有効なものを使って確認します。
ワンクッションが不要なコメントは自動で表示され、必要なコメントは内容が隠れたまま案内が表示されます。
「内容を見る」を選ぶと、その1件だけを表示できます。

対応する画面で、ページを再読み込みせずに別の動画へ切り替えた場合は、前の動画で「内容を見る」を押して表示した状態を解除し、新しい動画のコメントの確認を再開しようとします。
コメントの確認が再開されない場合や再読み込みの案内が出た場合は、ページを再読み込みしてください。
返信は対象外です。対応を確認していない画面構成もあります。

Shortsでの操作は、YouTube Shorts（YouTube ショート動画）のコメント欄をご覧ください。

YouTube Shorts（YouTube ショート動画）のコメント欄

拡張機能が対応する画面構成で表示される、返信ではないコメントが対象です。

  1. YouTube Shortsの動画を開き、コメントボタンを押してコメント欄を開きます。
  2. ワンクッションが必要と判定されたコメントは、内容を隠した状態で「内容を見る」ボタンが表示されます。ワンクッションが不要と判定されたコメントは自動で表示されます。
  3. 隠れているコメントを読みたい場合は、そのコメントの「内容を見る」を押してください。選んだコメントだけを表示します。
  4. コメント欄を閉じて開き直すと、「内容を見る」で表示した状態はいったん解除され、現在の設定に基づいてコメントをもう一度確認します。ワンクッションが必要なコメントは再び隠れます。

設定の変更が反映されない場合や、再読み込みの案内が表示された場合は、YouTube Shortsのページを再読み込みしてください。

返信コメントは、現在のワンクッション機能の対象外です。

Studioの動画コメント

YouTube Studioで対象の動画を選び、その動画の「コメント」を開きます。
本文を隠した状態で、返信ではない対象コメントを、標準の13個の言葉と登録した言葉のうちワンクッションが有効なものを使って確認します。
ワンクッションが不要なコメントは自動で表示され、必要なコメントは内容が隠れたまま案内が表示されます。
「内容を見る」を選ぶと、その1件だけを表示できます。

画面内で別の動画に切り替えたときなどは、対象の本文を隠したまま再読み込みを案内する場合があります。
案内が出たらページを再読み込みし、現在の動画のコメント欄を確認してください。
チャンネル全体のコメント管理画面、Shorts専用コメント管理画面、返信は対象外です。

ワンクッション後のコメントを個別に表示する

ワンクッションが表示されたコメントは、無理に読む必要はありません。内容を確認したいと思ったときに、ご自身の判断で「内容を見る」を選択してください。

選択したコメントだけを表示する機能です。コメント内容や画面の状態が変わったときなどには、一度表示したコメントが再び隠れる場合があります。

登録した言葉の設定をコメント欄に反映する

設定を保存すると、開いているYouTubeライブチャット、通常動画、YouTube Shorts（YouTubeショート動画）、YouTube Studioの対象コメント欄への反映を試みます。

  1. 設定画面で登録した言葉の設定を変更します。
    言葉の追加・編集・削除、全体や言葉ごとのON/OFF、インポート、リセットが対象です。
  2. 設定画面で保存完了を確認します。
    保存結果が不明な場合は、制限・うまく動かない場合をご覧ください。
  3. 対象のコメント欄で変更が反映されたか確認します。
    変更が反映されない場合は、該当する画面を閉じて開き直すか、ページを再読み込みしてください。

設定画面の保存完了表示は、設定が保存されたことを示します。
ただし、すべての対象画面に変更が反映されることは保証されません。反映までにかかる時間も確約できません。

エクスポートで設定をバックアップする

  1. 入力欄を空にし、編集中の言葉があれば保存またはキャンセルします。
    入力・編集中はエクスポートできません。
  2. 「バックアップ」の「エクスポート」を選び、バックアップファイル（JSON形式）を端末に保存します。

ファイルの保存画面はOSや利用環境によって異なります。

ファイルには、登録した言葉と、全体および言葉ごとのON/OFF設定が含まれます。
OFFにした言葉も含まれます。
未保存の入力内容、表示言語設定、標準の13個の言葉は含みません。

バックアップファイルには登録した言葉がそのまま記録されます。
保存先と共有相手にご注意ください。

インポートでバックアップから設定を復元する

インポートは既存の登録内容への追加ではありません。
現在登録されている言葉とON/OFF設定は、選択したバックアップファイルの内容に置き換わります。現在の登録内容を残しておきたい場合は、事前にエクスポートしてください。

  1. 現在の登録内容も残したい場合は、先にエクスポートします。
  2. 入力欄を空にし、編集中の言葉を保存またはキャンセルします。
    「バックアップ」の「インポート」から、この拡張機能でエクスポートしたバックアップファイルを選びます。
  3. 件数やON/OFFなどの確認表示を読み、問題がなければ「取り込んで置き換える」を選びます。
    取りやめる場合は「キャンセル」を選びます。
  4. 保存完了を確認し、コメント欄で設定の反映を確認する手順に沿って変更が反映されたか確認します。

入力・編集中はインポートできません。表示言語設定と標準の判定ルールは変更されません。

リセットで登録した言葉の設定を初期状態に戻す

入力・編集中はリセットできません。

  1. 入力欄を空にし、編集中の言葉を保存またはキャンセルします。
    必要な場合は事前にエクスポートでバックアップします。
  2. 「設定のリセット」の「リセットする」を選び、確認表示を読みます。
  3. よければ「リセットを実行する」を選びます。
    取りやめる場合は「キャンセル」を選びます。
  4. 保存完了を確認し、コメント欄で設定の反映を確認する手順に沿って変更が反映されたか確認します。

登録した言葉とその個別設定をすべて削除し、「登録した言葉へのワンクッション」はON、登録した言葉は0件の初期状態に戻します。
表示言語設定と、標準の13個の言葉を使う判定ルールは変更しません。

制限・うまく動かない場合

  • 登録した言葉の設定や表示言語を保存しても反映されない場合は、該当するLive ChatやShortsのコメント欄を閉じて開き直すか、該当ページを再読み込みしてください。
    ポップアップの表示言語が変わらない場合は、開き直してください。
  • コメントが隠れたまま再読み込み案内が出た場合は、案内に従ってページを再読み込みしてください。
    通常動画の切り替え後にコメントの確認が再開されない場合や、Studioで別の動画に切り替えた後に案内が出た場合も、再読み込みして現在の動画のコメント欄を確認してください。
  • 登録した言葉の設定が保存されたか確認できないという案内が出た場合は、開いている対象のYouTubeライブチャット、通常動画、Shorts、Studioのコメント画面をすべて閉じてください。
    その後、設定画面を再読み込みし、保存内容を確認してください。
  • 表示言語の保存結果が不明な場合は、設定画面を再読み込みし、表示言語を確認してください。
  • 開発版のプログラムを更新した場合は、Chromeの「拡張機能を管理」でこの拡張機能を再読み込みしてから、対象のYouTubeページを再読み込みするか、閉じて開き直してください。
  • 現在の対象範囲を確認してください。
    返信やSuper Chatなどは対象外または未検証です。
  • YouTube側の画面変更が影響している可能性もあります。
    開発中のため、未実装・未検証の範囲があります。

ワンクッションが表示されないことは、そのコメントが安全であることを意味しません。
動作に不安がある場合は、コメントから離れることも選べます。
