はじめに

このマニュアルは、開発中のプロトタイプ v0.1.0 を対象としたサンプルです。
Chrome ウェブストアには未公開です。
開発確認用として、すでにGoogle Chrome 拡張機能を読み込んでいる方に向けて説明します。

YouTubeライブ配信のコメント（Live Chat）のうち、通常のメッセージが対象です。
通常動画とYouTube Studio「動画のコメント」では、対応するトップレベルコメントが対象です。
いずれも標準13語句と有効な登録語句を共通のルールで判定し、Google Chrome 拡張機能の表示は日本語・英語に対応しています。
返信やSuper Chatなどは対象外で、未知の画面構造での動作は未確認です。
詳しくは現在の対象範囲をご覧ください。

「こめんとみまもり Live」設定画面へのポップアップを開く

  1. Chromeの「拡張機能」メニューから「こめんとみまもり Live」を選び、オプションポップアップを開きます。
    ツールバーに固定している場合は、そのアイコンからも開けます。
  2. 「詳細設定を開く」を選ぶと、オプション画面が新しいタブで開きます。

オプションポップアップでは製品名・バージョンを確認できます。
登録語句や表示言語はオプション画面で変更します。

オプションと表示言語

オプション画面には、表示言語、登録語句の管理、標準のワンクッションの説明、バックアップ、設定のリセットがあります。
登録語句の各操作は自動保存されるため、画面に表示される保存結果を確認してください。

自動／日本語／English

  • 自動：ChromeのUI言語が日本語系なら日本語、それ以外なら英語で表示します。
  • 日本語／English：オプション画面、オプションポップアップ、Live Chat・通常動画・Studioの動画コメント欄のGoogle Chrome 拡張機能の表示に、選択した言語を使います。

言語設定は自動保存されます。
入力・編集中の切替には確認があり、保存成功後に未保存の入力内容がクリアされます。
必要な編集は先に保存してください。

オプションポップアップは次に開いたときに保存済みの言語を使います。
保存後、開いている対象のコメント欄にも新しい表示言語の反映を試みます。
すべての画面への通知到達や、反映の完了・所要時間は保証されません。
反映されないときは、該当のLive Chatを閉じて開き直すか、通常動画・Studioの該当ページを再読み込みしてください。

表示言語だけの変更では、コメントの判定・遮蔽・手動表示の状態が保たれます。
変更するのはGoogle Chrome 拡張機能の表示で、コメント本文や登録語句は翻訳しません。
このWebページの日英切替は、Google Chrome 拡張機能の表示言語設定を変更しません。

距離を置きたい言葉を管理する

各操作の後はオプション画面に表示される保存結果を確認し、登録語句設定を反映する手順に沿って対象画面での反映を確認してください。

  1. 追加：「言葉を追加」に2〜50文字の語句を入力し、「追加する」を選びます。
    最大30件まで登録できます。
  2. 編集：登録した語句の「編集」を選び、内容を変更して「保存」します。
    取りやめるときは「キャンセル」を選びます。
  3. 削除：対象の「削除」を選び、確認後に削除します。
  4. Master ON/OFF：「登録した言葉へのワンクッション」で、登録語句による判定全体を切り替えます。
  5. 個別ON/OFF：各語句のスイッチで、その語句を判定に使うかを切り替えます。

重複した語句や改行、一部の特殊な文字などは登録できません。
入力案内が出た場合は内容を確認してください。

標準ルールは独立しています。
標準13語句によるワンクッションは、Masterや個別語句をOFFにしても有効です。
MasterはGoogle Chrome 拡張機能全体のON/OFFではありません。

Live Chatのワンクッション

対象コメントは本文を先に隠します。
SAFEと判定した本文は自動表示し、CUSHIONと判定した本文は隠したままワンクッションを表示します。
読みたい場合は、そのコメントの「内容を見る」を選んでください。
英語表示のボタンは「View Comment」です。

この操作（Manual Reveal）で表示するのは当該コメントだけです。
他のコメントを一括表示する操作ではなく、本文などの状態が変わると、表示の許可が解除される場合があります。

コメントを自動削除したり、投稿者を評価・制裁したりする機能ではありません。
判定できない場合などは本文が隠れたままになることもあります。
すべてのコメントや表示経路への保護は保証していません。

登録語句設定や表示言語を保存すると、開いているLive Chatにも反映を試みます。
反映されない場合は、該当のLive Chatを閉じて開き直してください。

通常動画コメントのワンクッション

通常のYouTube動画ページ（/watch・/live）でコメント欄を開きます。
対応するトップレベルコメントの本文を先に隠し、標準13語句と有効な登録語句で判定します。
SAFEの本文は自動表示され、CUSHIONの本文はワンクッションで隠れます。
「内容を見る」を選ぶと、その1件だけを表示できます。

対応するページ内の動画切替（SPA）では、前の動画での手動表示を引き継がず、現在の動画のコメントを再判定して自動復帰を試みます。
復帰しない場合や再読み込み案内が出た場合は、ページを再読み込みしてください。
返信やShortsは対象外で、未知の画面構造での保護は確認できていません。

Studioの動画コメント

YouTube Studioで対象の動画を選び、その動画の「コメント」を開きます。
トップレベルコメントの本文を先に隠し、標準13語句と有効な登録語句で判定します。
SAFEの本文は自動表示され、CUSHIONの本文はワンクッションで隠れます。
「内容を見る」を選ぶと、その1件だけを表示できます。

画面内で別の動画に切り替えたときなどは、対象の本文を隠したまま再読み込みを案内する場合があります。
案内が出たらページを再読み込みし、現在の動画のコメント欄を確認してください。
チャンネル全体のコメント管理画面や返信は対象外です。

登録語句設定を反映する

登録語句の追加・編集・削除・Master／個別ON/OFFの変更、Import・Resetの保存後に、開いているLive Chat、通常動画、Studioの対象コメント欄への反映を試みます。

  1. オプション画面で登録語句設定を変更する。
  2. 保存完了を確認する。
    保存結果が不明な場合は、制限・うまく動かない場合をご覧ください。
  3. 対象画面で変更が反映されたか確認する。
    反映されない場合は、該当のLive Chatを閉じて開き直すか、通常動画・Studioの該当ページを再読み込みしてください。
    ページを閉じて開き直しても確認できます。

オプション画面の保存完了表示は、設定が保存されたことを示します。
すべての画面への通知到達・反映完了や、反映時刻・所要時間は保証されません。

Export：バックアップを保存する

  1. 入力欄を空にし、編集中の語句があれば保存またはキャンセルします。
    入力・編集中はExportを利用できません。
  2. 「バックアップ」の「エクスポート」を選び、JSONファイルをローカルに保存します。

保存済みの登録語句と、Master・個別ON/OFF設定を出力します。
OFFの語句も含みます。
未保存の入力内容、表示言語設定、標準13語句は含みません。

JSONには登録語句が平文で、そのまま記載されます。
保存先と共有相手にご注意ください。

Import：バックアップから復元する

  1. 現在の登録内容も残したい場合は、先にExportします。
  2. 入力欄を空にし、編集中の語句を保存またはキャンセルします。
    「バックアップ」の「インポート」から、このGoogle Chrome 拡張機能でExportしたJSONファイルを選びます。
  3. 件数やON/OFFなどの確認表示を読み、問題がなければ「取り込んで置き換える」を選びます。
    取りやめる場合は「キャンセル」を選びます。
  4. 保存完了を確認し、登録語句設定を反映する手順に沿って対象画面での反映を確認します。

Importは全体置き換えです。
現在の登録語句への追加ではなく、登録語句とMaster・個別ON/OFF設定をファイルの内容で置き換えます。
表示言語設定と標準ルールは変更しません。

Reset：登録語句設定を初期化する

  1. 入力欄を空にし、編集中の語句を保存またはキャンセルします。
    必要な場合は事前にExportでバックアップします。
  2. 「設定のリセット」の「リセットする」を選び、確認表示を読みます。
  3. よければ「リセットを実行する」を選びます。
    取りやめる場合は「キャンセル」を選びます。
  4. 保存完了を確認し、登録語句設定を反映する手順に沿って対象画面での反映を確認します。

登録語句と個別ON/OFF設定を削除し、Master ON・登録0件の初期状態に戻します。
表示言語設定と標準13語句のルールは変更しません。

制限・うまく動かない場合

  • 登録語句設定や表示言語を保存しても反映されない場合は、該当のLive Chatを閉じて開き直すか、通常動画・Studioの該当ページを再読み込みしてください。
    オプションポップアップの表示言語が変わらない場合は、開き直してください。
  • コメントが隠れたまま再読み込み案内が出た場合は、案内に従ってページを再読み込みしてください。
    通常動画の切替後にコメント欄が復帰しない場合や、Studioで別の動画に切り替えた後に案内が出た場合も、再読み込みして現在の動画のコメント欄を確認してください。
  • 登録語句設定の保存結果を確認できないという案内がオプション画面に出た場合は、その案内に従ってください。
    開いている対象画面をすべて閉じてから、オプション画面を再読み込みし、保存内容を確認してください。
    表示言語の保存結果が不明な場合は、オプション画面を再読み込みして確認してください。
  • 現在の対象範囲を確認してください。
    返信やSuper Chatなどは対象外または未検証です。
  • YouTube側の画面変更が影響している可能性もあります。
    開発中のため、未実装・未検証の範囲があります。

ワンクッションが表示されないことは、そのコメントが安全であることを意味しません。
動作に不安がある場合は、コメントから離れることも選べます。
