はじめに

このマニュアルは、開発中のプロトタイプ v0.1.0 を対象としたサンプルです。
Chrome Web Storeには未公開です。
開発確認用として、すでに拡張機能を読み込んでいる方に向けて説明します。

主な対象はLive Chatの通常コメントです。
通常動画・Studio「動画のコメント」は技術検証段階で、Live Chatと同じ判定・日英表示には対応していません。
詳しくは現在の対象範囲をご覧ください。

Popupを開く

  1. Chromeの拡張機能メニュー、またはツールバーに固定した「こめんとみまもり Live」のアイコンを選び、Popupを開きます。
  2. 「詳細設定を開く」を選ぶと、Options（設定画面）が新しいタブで開きます。

Popupでは製品名・バージョンを確認できます。
登録語句や表示言語はOptionsで変更します。

Optionsと表示言語

Optionsには、表示言語、登録語句の管理、標準のワンクッションの説明、バックアップ、設定のリセットがあります。
登録語句の各操作は自動保存されるため、画面に表示される保存結果を確認してください。

自動／日本語／English

  • 自動：ChromeのUI言語が日本語系なら日本語、それ以外なら英語で表示します。
  • 日本語／English：選択した言語でOptions、Popup、Live ChatのワンクッションUIを表示します。

言語設定は自動保存されます。
入力・編集中の切替には確認があり、保存成功後に未保存の入力内容がクリアされます。
必要な編集は先に保存してください。

Popupは次に開いたとき、Live Chatは新規起動または再読み込み時に言語を反映します。
言語だけの変更では、すべてのLive Chatを閉じる必要はありません。
開いているLive Chatへのリアルタイム反映は行いません。

このWebページの日英切替は、拡張機能の表示言語設定を変更しません。
通常動画・Studioの動画コメントUIの言語切替は未対応です。

距離を置きたい言葉を管理する

操作前に、登録語句設定を反映する手順（D-1）に従って、すべてのLive Chatを閉じてください。

  1. 追加：「言葉を追加」に2〜50文字の語句を入力し、「追加する」を選びます。
    最大30件まで登録できます。
  2. 編集：登録した語句の「編集」を選び、内容を変更して「保存」します。
    取りやめるときは「キャンセル」を選びます。
  3. 削除：対象の「削除」を選び、確認後に削除します。
  4. Master ON/OFF：「登録した言葉へのワンクッション」で、登録語句による判定全体を切り替えます。
  5. 個別ON/OFF：各語句のスイッチで、その語句を判定に使うかを切り替えます。

重複した語句や改行、一部の特殊な文字などは登録できません。
入力案内が出た場合は内容を確認してください。

標準ルールは独立しています。
標準13語句によるワンクッションは、Masterや個別語句をOFFにしても有効です。
Masterは拡張機能全体のON/OFFではありません。

Live Chatのワンクッション

対象コメントには、本文を読む前にワンクッションを表示します。
読みたい場合は、そのコメントの「内容を見る」を選んでください。
英語表示のボタンは「View Comment」です。

この操作（Manual Reveal）で表示するのは当該コメントだけです。
他のコメントを一括表示する操作ではなく、本文などの状態が変わると、表示の許可が解除される場合があります。

コメントを自動削除したり、投稿者を評価・制裁したりする機能ではありません。
判定できない場合などは本文が隠れたままになることもあります。
すべてのコメントや表示経路への保護は保証していません。

登録語句設定を反映する（D-1）

登録語句の追加・編集・削除・Master／個別ON/OFFの変更、およびImport・Resetでは、次の順序を守ってください。

  1. すべてのLive Chatを閉じる。
    通常の視聴ページ内、Studio内、ポップアウトなど、開いているLive Chatをすべて閉じます。
  2. Optionsで登録語句設定を変更する。
    Import・Resetも、この段階で行います。
  3. 保存完了を確認する。
    結果を確認できない場合は、Optionsを再読み込みして保存状態を確認してください。
  4. 新しくLive Chatを開く。
    新しいLive Chatで保存済みの設定を使います。

すでに開いているLive Chatへ、登録語句設定を動的に反映する機能は未実装です。
設定変更前にすべて閉じ、保存後に開き直してください。

表示言語だけを変更する場合は全閉鎖は不要です。
新しい言語は、Live Chatの新規起動または再読み込みで反映します。

Export：バックアップを保存する

  1. 入力欄を空にし、編集中の語句があれば保存またはキャンセルします。
    入力・編集中はExportを利用できません。
  2. 「バックアップ」の「エクスポート」を選び、JSONファイルをローカルに保存します。

保存済みの登録語句と、Master・個別ON/OFF設定を出力します。
OFFの語句も含みます。
未保存の入力内容、表示言語設定、標準13語句は含みません。

JSONには登録語句が平文で、そのまま記載されます。
保存先と共有相手にご注意ください。

Import：バックアップから復元する

  1. D-1の手順で、すべてのLive Chatを閉じます。
    現在の登録内容も残したい場合は、先にExportします。
  2. 入力欄を空にし、編集中の語句を保存またはキャンセルします。
    「バックアップ」の「インポート」から、この拡張機能でExportしたJSONファイルを選びます。
  3. 件数やON/OFFなどの確認表示を読み、問題がなければ「取り込んで置き換える」を選びます。
    取りやめる場合は「キャンセル」を選びます。
  4. 保存完了を確認して、新しくLive Chatを開きます。

Importは全体置き換えです。
現在の登録語句への追加ではなく、登録語句とMaster・個別ON/OFF設定をファイルの内容で置き換えます。
表示言語設定と標準ルールは変更しません。

Reset：登録語句設定を初期化する

  1. 必要な場合は事前にExportでバックアップし、D-1の手順で、すべてのLive Chatを閉じます。
  2. 「設定のリセット」の「リセットする」を選び、確認表示を読みます。
  3. よければ「リセットを実行する」を選びます。
    取りやめる場合は「キャンセル」を選びます。
  4. 完了を確認して、新しくLive Chatを開きます。

登録語句と個別ON/OFF設定を削除し、Master ON・登録0件の初期状態に戻します。
表示言語設定と標準13語句のルールは変更しません。

制限・うまく動かない場合

  • 登録語句の変更後は、すべてのLive Chatを閉じていたか、保存完了を確認したかを確かめ、新しくLive Chatを開いてください。
  • Optionsを再読み込みし、登録語句、Master ON/OFF、個別ON/OFFの保存状態を確認してください。
  • 現在の対象範囲を確認してください。
    返信やSuper Chatなどは対象外または未検証です。
  • YouTube側の画面変更が影響している可能性もあります。
    開発中のため、未実装・未検証の範囲があります。

ワンクッションが表示されないことは、そのコメントが安全であることを意味しません。
動作に不安がある場合は、コメントから離れることも選べます。
