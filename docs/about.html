こめんとみまもり Liveとは

「こめんとみまもり Live」は、YouTubeのコメントを読む前に、心に負荷がかかる可能性のある表現にワンクッションを置くGoogle Chrome拡張機能です。

コメントの内容を見るかどうかを、利用者様ご本人が選べることを大切にしています。
投稿者の人格評価・検閲・制裁を目的とした機能ではありません。

主な機能

現在は、主にYouTube Live Chatの通常コメントを対象として、次の機能を実装しています。

  • 標準のワンクッション：標準13語句のルールに該当するコメントにワンクッションを表示します。
  • 距離を置きたい言葉：自分で語句を登録し、登録語句全体のMaster ON/OFFと、各語句の個別ON/OFFを設定できます。
  • 内容を見る（Manual Reveal）：ワンクッションが表示された当該コメントだけを、自分の操作で確認できます。
  • Export・Import・Reset：登録語句とON/OFF設定のバックアップ・全体置き換えによる復元・初期化ができます。
  • 日本語・英語表示：Popup、Options、Live ChatのワンクッションUIに対応しています。
    コメント本文や登録語句を翻訳する機能ではありません。

Master OFFは、登録語句によるワンクッションを止める設定です。
標準ルールは登録語句のON/OFFとは独立して、引き続き有効です。

基本操作は操作マニュアル、データの取り扱いはプライバシーポリシーをご覧ください。

現在の対象範囲

YouTube Live Chat

中心的な対象は、通常の視聴ページ内・YouTube Studio内・ポップアウトで表示するLive Chatの通常コメントです。
標準13語句と登録語句を組み合わせた判定、およびワンクッションUIの日英表示に対応しています。

通常動画コメント・Studio「動画のコメント」

トップレベルコメントには、判定前に本文を隠す方式（Protect-first）の技術検証用PoCがあります。
Live Chatと同じ標準13語句・登録語句の統合判定や、表示言語切替には対応していません。
Live Chatと同等の保護機能としては利用できません。

対象外・未検証の範囲

返信コメント、Super Chat、Super Sticker、メンバーシップ通知などは対象外または未検証です。
大量コメント時の表示切替を含め、すべての表示経路を保護できることを確認したものではありません。

制限と注意事項

  • 開発中のプロトタイプです。
    Chrome Web Storeには未公開です。
  • ルールによる判定には、誤検知や見逃しが発生する可能性があります。
  • YouTube側の画面構造の変更などにより、正常に動作しない可能性があります。
  • すべてのコメント・表示経路の保護や、完全な安全性を保証するものではありません。

登録語句の変更をLive Chatへ反映するには、すべてのLive Chatを閉じてから設定を変更する手順に従ってください。
