こめんとみまもり Liveとは

「こめんとみまもり Live」は、YouTubeのコメントを読む前に、心に負荷がかかる可能性のある表現にワンクッションを置くGoogle Chrome拡張機能です。

コメントの内容を見るかどうかを、利用者様ご本人が選べることを大切にしています。
投稿者の人格評価・検閲・制裁を目的とした機能ではありません。

主な機能

対応するYouTubeライブ配信のコメント（Live Chat）、通常動画、YouTube Studioの動画コメントに、ワンクッションをかける機能を提供します。
標準ルールでは、現時点で心理的な負担につながりうる強い表現13語句を判定に使います。
有効な登録語句も同じ仕組みで判定し、標準語句か有効な登録語句に該当するコメントにワンクッションを表示します。
本文を先に隠してから判定する方式をProtect-firstと呼びます。
未判定の本文や、異常で判定できない本文は、既知の対象範囲では自動表示しません。

  • コメントの表示：SAFEと判定した本文は自動表示します。
    CUSHIONと判定した本文は隠したまま、ワンクッションを表示します。
  • 距離を置きたい言葉：自分で語句を登録し、登録語句全体のMaster ON/OFFと、各語句の個別ON/OFFを設定できます。
  • 内容を見る（Manual Reveal）：ワンクッションが表示された当該コメントだけを、自分の操作で確認できます。
  • Export・Import・Reset：登録語句とON/OFF設定のバックアップ・全体置き換えによる復元・初期化ができます。
  • 日本語・英語表示：Popup、Options、Live Chat・通常動画・Studioの動画コメント欄の拡張機能の表示に対応しています。
    コメント本文や登録語句を翻訳する機能ではありません。

Master OFFは、登録語句によるワンクッションを止める設定です。
標準ルールは登録語句のON/OFFとは独立して、引き続き有効です。

基本操作は操作マニュアル、データの取り扱いはプライバシーポリシーをご覧ください。

現在の対象範囲

YouTube Live Chat

通常の視聴ページ内・YouTube Studio内・ポップアウトで表示するLive Chatの通常コメントが対象です。

通常動画コメント

通常の動画ページ（/watch・/live）で、対応するトップレベルコメント（返信を除く）が対象です。
対応するページ内の動画切替後は、現在の動画のコメントを再判定し、自動復帰を試みます。

YouTube Studio「動画のコメント」

Studioで開いた個別の動画のトップレベルコメントが対象です。
画面内で別の動画に切り替えたときなどは、対象の本文を隠したまま再読み込みを案内する場合があります。

対象外・未検証の範囲

返信コメント、Studioのチャンネル全体のコメント管理画面、Super Chat、Super Sticker、メンバーシップ通知、Shortsは対象外です。
未知の画面構造や大量コメント時の表示切替を含め、すべての表示経路での保護は確認できていません。

制限と注意事項

  • 開発中のプロトタイプです。
    Chrome Web Storeには未公開です。
  • ルールによる判定には、誤検知や見逃しが発生する可能性があります。
  • YouTube側の画面構造の変更などにより、正常に動作しない可能性があります。
  • すべてのコメント・表示経路の保護や、完全な安全性を保証するものではありません。

登録語句設定や表示言語を保存すると、開いている対象のコメント欄への反映を試みます。
すべての画面への通知到達や、反映の完了・所要時間は保証されません。
反映されない場合の操作は、登録語句設定を反映する手順をご覧ください。
