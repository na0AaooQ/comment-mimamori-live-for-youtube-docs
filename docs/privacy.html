基本方針

このプライバシーポリシーは、「こめんとみまもり Live」v0.2.0 BETAの現行実装および公開資料Webサイトにおける情報の取り扱いについて説明するものです。

「こめんとみまもり Live」は利用者様のプライバシーを尊重し、コメント本文と判定結果をブラウザ内で取り扱う設計です。

拡張機能によるコメント処理、設定の保存、利用者様が保存するバックアップ、Webサイトのホスティングと埋め込み動画について説明します。

YouTubeのコメント本文と判定結果

このGoogle Chrome 拡張機能は、対応するYouTubeのコメント本文と判定結果を、利用者様のブラウザ内で処理します。

  • 判定のためにコメント本文を外部サーバーへ送信しません。判定結果も外部へ送信しません。
  • コメント本文や判定結果を継続的に保存しません。
  • 外部AIによるコメント判定は行いません。

これは本機能による処理についての説明です。YouTube自体によるコメントの保存や通信は、YouTubeのサービスの取り扱いに従います。

保存する設定情報

次の設定は、Google Chromeの端末内の保存領域（chrome.storage.local）に保存します。

  • 利用者様が「距離を置きたい言葉」に登録した言葉
  • 「登録した言葉へのワンクッション」のON/OFF
  • 登録した言葉ごとのON/OFF
  • 表示言語設定（自動／日本語／English）

登録した言葉は設定として保存します。YouTubeのコメント本文や判定結果は、設定として保存しません。
設定の保存にはChromeのクラウド同期を使いません。
設定変更の反映先となる画面を把握するための情報などは、ブラウザ内で一時的に扱います。

登録した言葉は設定画面で個別に削除できます。リセットすると、登録した言葉と個別設定をすべて削除し、「登録した言葉へのワンクッション」はON、登録した言葉は0件に戻ります。
リセットで表示言語は変わりません。標準の13個の言葉による判定は、登録した言葉のON/OFFとは独立して動作します。

エクスポート・インポートとバックアップファイル

登録した言葉と、全体および言葉ごとのON/OFF設定は、バックアップファイル（JSON形式）として端末に保存できます。
OFFにした言葉も含まれます。
未保存の入力内容、表示言語設定、標準の13個の言葉は含まれません。

エクスポートしたファイルには、登録した言葉がそのまま記録されます。
ファイルの保存場所や共有相手は、ご自身で確認してください。
拡張機能がこのファイルを外部サーバーへアップロードする機能はありません。

インポートでは、選んだファイルの内容を確認してから、現在の登録内容とON/OFF設定をすべて置き換えます。
表示言語設定は変更しません。

操作方法はエクスポート・インポート、保存後の確認はコメント欄で設定の反映を確認する手順をご覧ください。

現在の拡張機能で行わないこと

  • 投稿者の人格評価や、投稿者への制裁
  • コメントの自動削除
  • 外部AIによるコメント判定
  • 外部アクセス解析・テレメトリによる利用状況の収集

ワンクッションは、利用者様ご本人がコメントの内容を見るかどうかを選ぶためのものです。
これらは現行実装についての説明で、将来の機能変更時には説明を見直します。

WebサイトとGitHub Pages

このWebサイトの公開先はGitHub Pagesです。
Webページの閲覧に伴うホスティング側の処理は、拡張機能のコメント判定とは別のものです。

GitHub Pages上でページを閲覧すると、GitHubへのサインインの有無にかかわらず、セキュリティ目的で閲覧者のIPアドレスが記録・保存されます。
詳しくはGitHub公式のデータ収集に関する説明とGitHubのプライバシー声明をご確認ください。

このWebサイトでは、独自の外部アクセス解析やテレメトリを使用していません。Webサイト自身のCSS・JavaScript・操作説明用画像は、同じWebサイトから配信しています。
外部サイトのリンクを開いた場合は、移動先のサイトでの取り扱いが適用されます。

YouTubeの埋め込み動画について

このWebサイトの操作マニュアルには、YouTubeのプライバシー強化モードを使用した操作イメージ動画を掲載しています。

動画の表示を選択すると、利用者様のブラウザがYouTubeおよび関連サービスに接続します。動画の表示や視聴に伴う情報の取り扱いについては、Googleのプライバシーポリシーをご確認ください。

動画を表示・視聴しなくても、操作マニュアルをご利用いただけます。
