基本方針

利用者のプライバシーを尊重し、コメント本文と判定結果をブラウザ内で取り扱う設計です。
このページは、v0.1.0の現行実装に基づく、開発中のプロトタイプ用の暫定的なプライバシー説明です。

拡張機能によるコメント処理、設定の保存、利用者が保存するバックアップ、Webサイトのホスティングを区別して説明します。

コメント本文・判定結果

現在の拡張機能は、対象コメントの本文と判定結果をブラウザ内のメモリ上で処理します。

  • コメント本文を判定用の外部サーバーへ送信しません。
  • コメント本文を拡張機能が永続保存することはありません。
  • 判定結果を外部送信・永続保存しません。
  • 外部AIによるコメント判定は行いません。

これは本拡張機能による処理の説明です。
YouTube自体によるコメントの保存・通信などは、YouTube側のサービスの取り扱いに従います。

保存する設定情報

次の設定を、Chrome拡張機能のローカル保存領域 chrome.storage.local に保存します。

  • 利用者が登録した「距離を置きたい言葉」
  • 登録語句全体のMaster ON/OFF
  • 各登録語句の個別ON/OFF
  • 表示言語設定（自動／日本語／English）

登録語句は設定として保存しますが、コメント本文や判定結果を設定として保存するものではありません。
設定の保存先はChromeのローカル領域で、クラウド同期用の保存領域は使用しません。

登録語句を削除する場合はOptionsで個別に削除するか、Resetを利用できます。
Resetで表示言語設定は変更されません。

Export・ImportとJSONファイル

保存済みの登録語句とMaster・個別ON/OFF設定を、ローカルのJSONファイルへExportできます。
OFFの語句も含みます。
未保存の入力内容、表示言語設定、標準13語句はExport対象外です。

Exportファイルには登録語句が平文で含まれます。
ファイルの保存場所や共有相手は、ご自身で確認してください。
拡張機能がこのファイルを外部サーバーへアップロードする機能はありません。

Importは、選択したJSONを確認後、現在の登録語句設定を全体置き換えします。
既存の語句への追加ではありません。
表示言語設定は変更しません。

操作方法はExport・Import、設定の反映はD-1の手順をご覧ください。

現在の拡張機能で行わないこと

  • 投稿者の人格評価や、投稿者への制裁
  • コメントの自動削除
  • 外部AIによるコメント判定
  • 外部アクセス解析・テレメトリによる利用状況の収集

ワンクッションは、利用者本人がコメントの内容を見るかどうかを選ぶためのものです。
これらは現行実装についての説明で、将来の機能変更時には説明を見直します。

WebサイトとGitHub Pages

このWebサイトの公開先はGitHub Pagesです。
Webページの閲覧に伴うホスティング側の処理は、拡張機能のコメント判定とは別のものです。

GitHub Pages上でページを閲覧すると、GitHubへのサインインの有無にかかわらず、セキュリティ目的で閲覧者のIPアドレスが記録・保存されます。
詳しくはGitHub公式のデータ収集に関する説明とGitHubのプライバシー声明をご確認ください。

このWebページ自体には、外部アクセス解析、テレメトリ、外部CDN、外部JavaScriptを追加していません。
外部サイトのリンクを開いた場合は、移動先のサイトでの取り扱いが適用されます。
